How it works

Four stages from raw telecom dumps to evidence that stands up in court.

01

Ingest

Upload CDR, IPDR, tower registry, tower dumps, and subscriber (SDR) data - CSV, XLS, XLSX or TXT. Operator-aware column mapping handles real ISP dump formats, with preview, append-or-replace modes, and a validation report of every coerced or dropped row.

02

Analyze

Force-directed network graphs, six tower-map modes, entity timelines with Gantt session bars, and 20 chart types. Two-layer service attribution - longest-prefix CIDR over 62 providers plus a 264-rule port table shared by both engines.

03

Investigate

The inference engine scores subjects 0-100 and flags impossible travel, SIM clones, convoys, hidden links, beaconing, and VPN usage. Cross-case linking spots reoffenders. A fine-tuned local LLM answers questions and drafts reports - no cloud.

04

Report

Pin findings, chart snapshots and flagged records into a per-case evidence folder, then generate an official, print-to-PDF case dossier - letterhead, persons of interest, key findings, methodology - with every action on an append-only audit trail.

Features

Twenty-two functional areas purpose-built for forensic investigation workflows.

Data Ingestion

CDR / IPDR Upload

Voice, SMS and IP-session records. CSV, XLS, XLSX, TXT. Preview before commit, append or replace per upload, all data scoped per case.

Operator Column Mapping

Aliased headers from Airtel/Jio/Vi/BSNL-style dumps resolve onto canonical fields, with an editable mapping UI and row-by-row date parsing.

Import Validation Report

Every upload reports rows imported, dropped and date-coerced - with example dropped rows - so silent misparsing can't happen.

Permanent Tower Repository

Global tower master auto-harvested from every upload. Upsert semantics never clobber coordinates; offline reverse-geocoding fills city/state.

Subscriber (SDR) Data

Enrich subjects with subscriber profiles, global by MSISDN. Identity cards appear on profiles and flow into dossier persons-of-interest.

Dashboard

KPI Summary

Records, reconstructed sessions, top contact, top service, unique subjects, geo-fenced counts and activity spikes - at a glance.

Data Quality Score

0-100 completeness score with a transparent penalty breakdown - missing towers, coordinates, durations, invalid timestamps.

Period Comparison

Compare two date ranges: volume deltas, new/lost/shared contacts, subjects, towers, and service-usage changes.

Cross-Case Hits Panel

Subjects from this case that also appear in other cases surface on the dashboard the moment the case opens.

Network Graph

Server-Built Bounded Graph

D3 force layout over a top-N heaviest-edge subgraph with true full-coverage node weights - never assembles 500k records in the browser.

Canvas at Scale

Large networks switch to a canvas force renderer: zoom, pan, hover, search-highlight and per-node drag stay smooth into the thousands of nodes.

CDR/IPDR Separation

Call and IP networks render as disjoint components with distinct colours. No false cross-attribution, ever.

Centrality & Communities

PageRank, degree/betweenness leaderboards, greedy-modularity communities and structural bridges via NetworkX.

Tower Map - 6 Modes

Movement Path

Chronological legs graded by estimated travel mode (walking -> road -> rail -> air -> impossible), with direction arrows and a playback scrubber.

Heatmap & Zones

Gaussian density surface weighted by visit count, plus operational-zone circles - every location stays clickable.

Meetings & Co-location

Server-side exact co-location detection across the whole case, colour-coded by time gap with High/Medium/Low confidence.

Triangulation

Tech-aware coverage cells (1-15 km) with inverse-variance weighted position fixes, uncertainty circles and Turf.js overlap polygons.

Inference Overlays & Geofence

Impossible-travel legs, co-presence pairs and home/work anchors drawn on the map; draw a polygon to list every subject inside it.

Timeline & Session Intelligence

Entity Timeline

Lazy, paginated entity cards with activity-density strips, Gantt session bars coloured by service (100+), and side-by-side comparison.

Session Reconstruction

IPDR rows bucket into concurrent (peer, activity-family) tracks split on family-adaptive idle gaps - interleaved apps stay separate sessions.

Service Attribution

Two-layer engine: longest-prefix CIDR over 62 providers, a shared 264-rule port table, behavioural fingerprinting and QUIC awareness.

Evidence-Grade Tooltips

Every session bar explains itself: confidence, evidence tree (infrastructure / ports / behaviour / signals), alternatives, and an integrity hash.

Inference Engine

Composite Risk Score

Per-subject 0-100 scoring with a transparent factor breakdown. Independent CDR and IPDR leaderboards, watchlist hits forced to Critical.

Movement & Co-presence

Impossible travel, home/work anchors, mobility footprint, convoy detection, and "met but never called" hidden links.

Identity & Device

SIM swap, clone and burner detection with clone corroboration (impossible travel + multi-handset), keyed on MSISDN.

Behavioural & VPN

Activity bursts (z-score), odd-hours share, periodic-contact cadence, going-dark shifts, beaconing, and scored VPN/proxy likelihood.

Investigation Workflow

Story - Narrative & Timeline

An auto-written case narrative plus one unified, day-grouped feed merging calls, movement, meetings, identity changes, cross-case links and AI findings.

Evidence Folder

Pin findings, chart snapshots, graph captures and flagged records into a per-case folder with a dedicated tab - it all flows into the dossier.

Court-Ready Dossier

Official print-to-PDF report: agency letterhead, classification banners, executive summary, POI cards, key findings, charts, methodology appendix.

Chain-of-Custody Audit

Append-only audit log of every login, upload, export, dossier and view - who, from where, against which case - surfaced in an admin panel.

Workspace & Intel Tags

Hypotheses with supported/refuted status, labelled relationships between subjects, and global intel tags that follow an identifier across cases.

Field Analysis Pack

CDR Analysis Reports

Per-subject report pack: first/last calls, single-call days, day/night split, ISD and other-state calls, OFF periods, IMEI/IMSI summaries, bank-SMS.

Group Compare

Pick N subjects and get common contacts, towers, cell-IDs, locations and IMEIs, plus a who-called-whom matrix.

Tower Dump Analysis

Numbers present across multiple crime scenes, elimination lists, under-tower listings, and SIM/IMEI multiplicity.

Telecom Reference

Offline lookups: number series -> operator/circle, ISD codes -> country, IMEI TAC -> make/model. No internet required.

Legal Framework (Laws)

Searchable Indian legal reference for CDR/IPDR work - BNSS, Telecom Act 2023, IT Act, BSA Sec. 63 certificates, retention and privacy safeguards.

Cross-Case & AI

Cross-Case Linking

Reoffenders detected by number, IMEI, IMSI or IP (low-confidence flagged). List and link-graph views, per-case rollups, open-in-case jumps.

Fine-Tuned Local AI

QLoRA fine-tuned Qwen2.5-3B with 3,218 training examples and five-agent orchestration - Q&A and report drafting, fully offline.

Investigation Command Center

One click runs a 12-module PoliceInvestigator: findings, identity, anomalies, sessions, network hierarchy, location, call details, temporal.

AI Insights & Leads

Ranked investigation leads, z-score activity spikes, subject summaries and suggested questions - with useful/false-positive feedback capture.

Security & Administration

Hardened Sessions

PBKDF2-SHA256 (210k iterations), HttpOnly cookies, sliding expiry, multi-session tracking with revoke-everywhere.

AFK Auto-Logout

Four-stage idle status (Active -> Idle -> Expiring -> Expired) with automatic session revocation after 10 minutes.

Admin User Management

Create, edit, deactivate and reset users with investigator/admin roles - plus the filterable audit-log panel.

Case Management

Every record scoped to a case. Create, switch, reset and delete cases; towers stay global; data persists across sessions.

Scale & Deployment

1-5M+ Record Cases

Bounded client mirror with server-side authoritative analytics, background full-load, and indexed longest-prefix IP matching (~14 microseconds/row).

Materialised Analytics

Event-driven, versioned analytics cache with incremental updates on append - dashboards and reports open instantly on revisit.

Optional Accelerators

Offline-first capability layer: PostgreSQL with SQLite fallback, optional Redis cache tier, Celery jobs, trigram/FTS5 search, partitioning.

One-File Windows Installer

PyInstaller + Inno Setup build: self-contained ARGUS.exe, zero configuration, air-gapped capable, ~122 MB installer.

Modular ES-Module Frontend

47 native ES modules - core, services, and one controller per feature - with no build toolchain, loading directly in the browser.

Architecture

Three-layer design built for air-gapped, self-contained deployment.

01

Data Layer

PostgreSQL primary with automatic SQLite fallback. SQLAlchemy ORM across 15 models. Optional Redis cache tier and Celery workers. Trigram and FTS5-accelerated search, opt-in partitioning.

02

Analysis Layer

FastAPI with 26 routers and 24 services. Pandas ingestion, NetworkX graph analytics, an in-process event bus driving materialised analytics, and a shared attribution knowledge base consumed by both engines.

03

Intelligence Layer

QLoRA fine-tuned Qwen2.5-3B, five-agent orchestration, a 12-module PoliceInvestigator, and the spatiotemporal inference engine. Court-ready dossier generation with chain-of-custody references.
